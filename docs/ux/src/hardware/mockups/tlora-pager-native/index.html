T-LoRa Pager screens at panel density

Each screen as 480×222 RGB565 pixels. The left copy puts one panel pixel on one physical pixel of this display, which on a Retina Mac (218–254 ppi) is close to the panel's roughly 227 ppi and so close to true size. The right copy enlarges the same pixels 4× without smoothing.
