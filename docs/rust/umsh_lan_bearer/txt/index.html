The DNS-SD TXT schema (lan-bearer.md § Discovery).

A participant’s record says which group it is on, which node it is, and—if it has a LoRa radio—the settings that radio uses, so a client knows before sending anything which meshes the LAN reaches.

Allocation-free: a radio’s responder formats each value into a stack buffer as it goes, and a browser parses with whatever lookup its mDNS library offers.
