pub fn button_timings() -> ButtonTimings
Expand description

The gesture timing shared by every display tracker.

One set of numbers across the class is the point: the same hold powers off a T-Echo and a Heltec V3, and muscle memory carries.

A click is at most 500 ms; a chord continues while presses are within 400 ms of each other. Holding for 1 s and releasing is Back; holding through 4 s powers off without waiting for the release, so the gesture confirms itself while the user is still committing to it.
