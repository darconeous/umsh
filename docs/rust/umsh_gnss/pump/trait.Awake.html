Expand description

A way to keep the board awake while the pump needs to hear the receiver.

A board whose UART loses data while it sleeps lets the pump sleep through the receiver’s output and keeps itself awake only when the fix has gone stale (see QUIET_MS). A board whose UART does not, or that never sleeps, passes ().
