Expand description

A communicator’s durable chat state.

Iterators are lazy and their items owned: taking a page, filtering, and stopping early cost only what they read, and a flash back end decodes each record as it is asked for. Items are results, because a read can fail partway through. The store is always a type parameter, never a trait object.
