Expand description

Carrying frames between the device node and the chats.

The device node’s callbacks run inside its pump, where the chats are not at hand: listen copies what the chats need into an Inbox, and wakes it on word of a frame sent. run feeds the inbox to the communicator’s node, sends the chats’ frames, carries out what else they ask of the device node, and keeps their timers. Nothing here names an executor, so a board runs it on whichever it has.

Functions§

listen
Copies what node, the device identity local_key‘s node, receives for the chats into inbox: text frames, other nodes’ identities, answers to pings, and the course of sessions with forward secrecy. It wakes the inbox on word of a frame sent. The channel rules for public and EMERGENCY are applied here: a frame they refuse is left for any other listener.
run
Feeds what reaches inbox to node, sends its frames through mesh, the device node, and keeps its timers, for as long as the board runs. sleep_until waits for a time on the node’s clock, and notify tells the interface that events wait for it.
