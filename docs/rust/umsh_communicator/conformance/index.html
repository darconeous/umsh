Expand description

The suite every ChatStore back end passes.

It drives the real text engine, and a second engine as the peer, so every batch it commits is one the engine produced. A back end supplies a Harness—how to make an empty store, arm a power cut, and mount again—and runs run, or each check on its own.

The power-cut check cuts power after each step of the commit order and holds what survives to the safety table on CommitStep.
