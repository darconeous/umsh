Struct CommunicatorNode 

Source 
pub struct CommunicatorNode<P, S = MemoryStore> { /* private fields */ }
Expand description

A communicator’s node, over the device’s own ULCP session reached through P, keeping its chats in S.

Every method borrows the node for the length of the call and no longer, so the interface and the board’s tasks can share it on one executor.

Hands the device what is waiting and takes in what it sent. The board calls this after the interface has taken an input, whenever the port has something, and at CommunicatorNode::next_deadline.

The chats start here, as the device identity, as soon as the device has reported it, and hold the device’s channels from then on.
