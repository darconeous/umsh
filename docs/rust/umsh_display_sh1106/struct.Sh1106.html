Turn the panel on or off without discarding GDDRAM, so a later set_display_on(true) restores the same frame instantly.

Source

pub async fn flush(&mut self, fb: &Sh1106Fb) -> Result<(), I::Error>

Push a full frame buffer to the panel.

SH1106 requires page-by-page writes. Column start is 0x02 because the SH1106’s internal GDDRAM has 132 columns but the visible panel starts at column 2.
