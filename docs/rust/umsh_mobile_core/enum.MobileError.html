AdministrativeSession

§

InvalidRegionCode

Text could not be read as a region code, or a supplied code was not exactly two octets.

§

UnsupportedCapability

The operation needs a capability this radio does not advertise.

§

ChannelNameNotAscii

A public channel name contained a non-ASCII byte. Canonicalization is an ASCII case fold, so such a name has no defined key.

§

ChannelNameTooLong

A public channel name exceeded the derivation input limit.

§

InvalidChannelKeyLength

A channel key was not exactly 32 octets.
