Source
Expand description

The properties the model covers.

A descriptor says how to read a property’s octets (its codec, from [umsh_ulcp::describe]), whether the device has it at all (the capability that gates it), and what may be done to it (its access and kind). The device is the authority on everything else: a value that fails to decode is held as the octets the device reported, and a write the device adjusts is reported as the device adjusted it.
