Expand description

The device’s own session, reached in process.

A local binding answers every request that carries a non-zero TID exactly once, so a LocalExchange holds a request until its answer comes and never gives up on one: a missing answer would be a bug in the device, not a condition to recover from. What the device publishes arrives on the same port, in order with the answers.

The exchange is not an attach. It resets no session state and displaces no host, and it reaches the device domain only.
