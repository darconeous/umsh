BME280 temperature-only forced acquisition. No background sampling.

Register map, timing and compensation: Bosch BST-BME280-DS001-23, sections 4.2, 5 and 9.1: https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf Callers retain exclusive bus access for the complete operation and must not cancel an I2C transfer on controllers without cancellation-safe DMA.

Modules§

service
Cancellation-safe mailbox between a host request and a dedicated sensor worker. A canceled waiter leaves acquisition running; sequence tags prevent the next request from consuming its result. One onboard sensor per service.

Functions§

probe
Detection performs no measurement and accepts only BME280 (not BMP280).
sample
Fresh measurement in tenths of a kelvin. The chip returns to sleep after each conversion; pressure, humidity and the IIR filter are disabled.
