Crate host_communicator 

Source
Expand description

A communicator on the host. The screen is a window at the T-LoRa Pager’s 480x222; the keyboard is the Pager’s keyboard.

Interactive (needs the window feature):

host-communicator
host-communicator --node DIR

The first shows the fixture’s chats. The second runs the communicator’s node, as the Pager does, with its settings served by a soft device that keeps its saved state and identity under DIR, and a device node on the LAN bearer.

Up and Down arrows or the mouse wheel turn the wheel; the Right arrow or a click presses it. Return, Backspace, Space, and the letters are the Pager’s; Shift is CAP, and Alt the orange key. With the fixture, Tab brings its next message in, as if it arrived. An identity asked for arrives two seconds later, as the fixture’s own clock has it.

Headless, for scripted runs and comparisons with the mockup:

host-communicator [--node DIR] --script steps.txt --out shots/

Each script line is one step: turn N (negative is up), press, enter, backspace, type TEXT (typed as it is), keys TEXT (pressed as Pager keys, so the modifiers and typing aids act on them), space, shift and alt (tapped), alt-down and alt-up, airtime SECONDS (spent airtime that returns in that long; 0 for none), arrive (the fixture’s next message arrives), identify (the identity asked for arrives at once), wait SECONDS (the board’s clock moves on, and the fixture’s with it), dark and lit (the panel goes dark and lights again), battery PERCENT [charging], battery-empty (with off for the blink’s dark half), first-run, shot NAME, which writes NAME.png into the output directory once everything has settled, or peek MS NAME, which writes it MS milliseconds into what the last steps started. # starts a comment. Each input takes 50 ms of the board’s clock.

Timing, and something for a profiler to watch:

host-communicator --bench N

Turns the wheel N times, down the list and back, and reports the mean layout and paint time of a frame.

Modules§

flash 🔒
The Pager’s chat partition, as a file: a flash in memory whose every write and erase also reaches the file, so the store finds its chats there when the simulator starts again.
mesh 🔒
The device node behind the window: a MAC of the device identity’s own, on the LAN bearer, as the Pager’s runs on its radio. It holds the channels and peers the device’s settings hold, the chats are fed what it receives, and they send through it. Other simulators, and phones on the network, are on the same group.
node 🔒
The communicator’s node behind the window, as the Pager runs it: its settings served by a soft device on this host, which keeps its saved state and identity in a directory, and its chats kept in a flash partition that is a file in the same directory.
