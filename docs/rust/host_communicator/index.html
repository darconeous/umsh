A communicator on the host. The screen is a window at the T-LoRa Pager’s 480x222; the keyboard is the Pager’s keyboard.

Interactive (needs the window feature):

host-communicator

Up and Down arrows or the mouse wheel turn the wheel; the Right arrow or a click presses it. Return, Backspace, and the letters are themselves.

Headless, for scripted runs and comparisons with the mockup:

host-communicator --script steps.txt --out shots/

Each script line is one step: turn N (negative is up), press, enter, backspace, type TEXT, or shot NAME, which writes NAME.png into the output directory. # starts a comment.

Timing, and something for a profiler to watch:

host-communicator --bench N

Turns the wheel N times, down the list and back, and reports the mean layout and paint time of a frame.
