Module mesh 

Source
Expand description

The device node behind the window: a MAC of the device identity’s own, on the LAN bearer, as the Pager’s runs on its radio. It holds the channels and peers the device’s settings hold, the chats are fed what it receives, and they send through it. Other simulators, and phones on the network, are on the same group.

It runs on a single-threaded runtime that the window’s loop drives between frames, so the node, the chats, and the window share a thread.
