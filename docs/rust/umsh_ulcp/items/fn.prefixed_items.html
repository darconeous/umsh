pub fn prefixed_items(value: &[u8]) -> PrefixedItems<'_> ⓘ
Expand description

Iterate the PUI-length-prefixed items of a whole-table value (properties documented with an item length prefix, such as PROP_HOST_RX_FILTERS).

Yields an error item for a malformed prefix or truncated body and then ends; validate the whole table before applying any of it.
