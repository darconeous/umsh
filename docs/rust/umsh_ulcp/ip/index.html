IP connectivity codecs (PROP_IPV4_*, PROP_IPV6_*, PROP_IP_*).

The structures of docs/protocol/src/ulcp-ip.md: family readiness, the per-family configuration, the addresses in effect, and the resolvers.

The usability predicates here are the boundary the whole subsystem is defined on. FamilyState::Ready means a usable address, a static configuration is validated against the same rule, and the two are the same function so that they cannot drift: a device that accepted a static address it would then refuse to call ready would be unreachable and say it was fine.
