Module avatar 

Source
Expand description

Avatars: the colors, lettering, and outline that identify a peer or a channel at a glance.

These follow the iOS app’s AvatarStyle, ChannelAvatar, and PeerAvatarShape, which are canonical. An avatar that differed between the phone and the device would read as a different node.
