Expand description

Everything the interface draws from.

Fields§

§status: StatusStrip§section: Section§chats: Chats

Newest first.

§peers: Peers

Saved peers, most recently heard first.

§wall_time: Option<u32>

The time, in Unix seconds, as the board last read its clock, when it is known. Ages are counted to it.

§conversation: Option<Conversation>

The open chat’s messages, while one is open.

§screens: Vec<Screen, 4>

The screens, the one shown last. The Chats screen is always first.

§node: &'static dyn Node§airtime_wait: Option<u16>

Seconds until sending is allowed again, while the airtime it may use is spent.

§banner: Option<Banner>

A message that arrived in a chat not on screen, shown for a moment.

§dark: bool

The panel is dark: nothing on it is being read.

§arrived: Vec<Arrived, MAX_CHATS>

The chats that got messages while the panel was dark, in the order they first did, for the screen the first of them woke it to.

§ending: Option<Ending>

The board is turning off: shown over everything, and the end of input.

§keyboard: Keyboard

What keys type: the focused field’s modifiers and aids.

§picker: Option<u8>

The character picker is open, with this character focused.

§glance: Option<Glance>

A brief card for a setting a key changed.
