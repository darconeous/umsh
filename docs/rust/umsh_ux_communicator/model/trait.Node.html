Expand description

The node behind the interface: where every chat’s messages are kept, what it knows of peers and channels, and the device’s settings. The interface holds only the chats and peers it lists and the open chat’s newest messages, and reads them from here.

Reads are answered at once. What changes in the node by itself is announced by the NodeEvents Node::next_event hands out, which the interface takes in through State::apply. How the node lets the board know events are waiting is the node’s own, and stays out of this trait.

A setting’s setter changes what its read reports at once. Its outcome follows as an event: NodeEvent::SettingsChanged once it is applied, perhaps adjusted, or NodeEvent::SettingRefused, after which the read reports the value in force.

fn send( &self, chat: ChatId, text: &str, reply_to: Option<MessageId>, forward_secret: bool, ) -> Option<Message>

Keeps text, sent now in reply to reply_to if it is a reply, as the newest message of chat, and returns the message as kept, or None when there is no room for it. With forward_secret it goes under a session with forward secrecy or not at all; without, never under one.
