Module text 

Source
Expand description

Message and draft text, shared rather than copied.

A screen’s views and both of its render trees each hold the text they draw. A message can be ten fragments long, and copies of a conversation’s worth of those would fill the stack while a frame is built, so a message’s text is kept once, on a heap the device chooses, and everything that shows it holds a counted reference. A draft is kept the same way, and copied anew with each edit.
