Module keyboard 

Source
Expand description

The keyboard as the interface types with it: Shift and Alt, each off, one-shot, or locked; the two typing aids; and what each text field allows of them. See the UX book’s Communicator Keyboard page.

This decides what a key types. It knows nothing of the board’s matrix, only of keys with a legend of their own and one under Alt, and of the text it is typed into only what it is told: which field is focused, whether it is being edited, and where its cursor is.
