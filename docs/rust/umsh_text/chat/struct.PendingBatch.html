Expand description

A composed message waiting to be stored.

Store, in order, the checkpoint, the archive deletes, the archives, and the mutations; then ChatFacade::commit releases the frames. If storing fails, ChatFacade::reject fails them instead. The frames cannot reach the radio any other way.

pub fn transmission_count(&self) -> usize

How many frames the message goes out in. For an original message this matches the archive count, but an edit’s frames carry the editing option while its replacement archive is re-encoded without it, so the two can fragment differently.
