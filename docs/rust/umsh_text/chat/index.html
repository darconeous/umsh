Allocated chat facade around the text engine (feature alloc).

ChatFacade owns an Engine and the state every platform keeps beside it: the channels a session can hold conversations in, the full keys learned for channel members known only by hint, and the bookkeeping that lets a rejected compose put the engine back the way storage last saw it. Conversations are typed ConversationKeys; platform address formats are codecs over them, outside this module.

Engine outputs leave the facade owned—bodies copied out of the engine’s render arena—and in the order the engine produced them. Frames for the radio leave only inside an Outbound, which only the facade makes:

  • ChatFacade::compose returns a PendingBatch that holds its frames until ChatFacade::commit releases them, after the platform has stored the batch’s checkpoint, archive changes, and transcript mutations. A failed store calls ChatFacade::reject instead, which fails the frames and rebuilds the engine from the checkpoints storage still holds.
  • ChatFacade::drain returns everything else the engine produced, with the frames that answer resend requests and ask for repairs. None of them allocates a wire ID, so none waits on storage.
