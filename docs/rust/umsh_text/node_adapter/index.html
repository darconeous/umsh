Module node_adapter 

Source
Expand description

Node-layer adapters for chat-style applications (feature node).

  • inbound_text classifies a received frame for a chat session, with the display rules of the well-known channels, and copies a text frame out of the receive callback for the ChatFacade.
  • TransmitQueue carries the facade’s transmissions to LocalNode sends, and maps acknowledgments and timeouts back onto the engine. Channel sends need the software-crypto feature.
  • Thin wrappers for applications that send and receive text directly on a peer connection or a bound channel.
