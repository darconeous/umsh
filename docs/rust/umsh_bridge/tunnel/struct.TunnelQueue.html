Struct TunnelQueue

pub struct TunnelQueue { /* private fields */ }
Expand description

Bounded, drop-oldest outbound queue for one tunnel.

A frame waiting for a tunnel that has failed or backed up is stale by definition, so the queue never grows to hold it: the oldest goes first, and a reconnect discards everything rather than flushing an old session’s frames into a new one. Single-consumer: one writer task drains one queue, which is what lets a single stored waker stand in for a full notification queue.
