pub async fn pump_writer<W: AsyncWrite + Unpin>(

Expand description

Drain one session of queue onto writer, emitting the idle keepalive whenever nothing has been written for a keepalive interval.

The session is the caller’s to name: pass the generation read right after the clear that opened it, so clearing the queue again is what ends this pump — and a pump that is spawned but not yet polled cannot adopt a successor’s session in the meantime.
