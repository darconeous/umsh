Module server 

Source
Expand description

The bridge server: listeners, per-client tunnels, and the one task that copies frames between them.

A client is a configured name with a pinned identity, so the interface set is fixed for the run and a disconnected client is an interface that is down rather than one that has gone away. That is what lets the hub hold a stable interface index and lets a reconnecting client resume its own identity rather than acquire a new one.
