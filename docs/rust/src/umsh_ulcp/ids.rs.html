67    /// Autonomous MAC-layer repeater/forwarding enable (`PROP_MAC_REPEATER_ENABLED`).
68    ///
69    /// First of the device-behavior settings range (70–95), which is
70    /// subdivided as 70–79 repeater and identity, 80–87 advertisement
71    /// policy (80–82 allocated, 83–87 spare), 88–93 positioning, 94–95
72    /// environmental sensing (94 illuminance, 95 spare — the board's
73    /// thermistor is the expected claimant). A
74    /// single-octet identifier is the scarce resource, so the positioning
75    /// range holds the enable toggle and the fix telemetry a host reads
76    /// and the device announces continually; the rarely-touched
77    /// positioning *configuration* lives in the extended device range
78    /// alongside `PROP_TIME`. A persisted, device-domain boolean: when
79    /// set, the device identity's on-board MAC forwards overheard routable
80    /// frames and advertises the `REP` capability bit. The advertised
81    /// *role* is a separate matter — see `IDENT_ROLE`.
82    pub const MAC_REPEATER_ENABLED: u32 = 70;
83    /// The device identity's complete signed node-identity blob
84    /// (`PROP_IDENT`), served through a deferred signing effect.
85    pub const IDENT: u32 = 71;
86    /// Advertised `ROLE` byte of the device identity (`PROP_IDENT_ROLE`).
87    /// Empty means "derive it from what the device is actually doing".
88    pub const IDENT_ROLE: u32 = 72;
89    /// Whether the device identity advertises the `MOB` capability bit

111    /// Locate-alert state (`PROP_ALERT`) — what the device is currently

115    pub const ALERT: u32 = 79;
116    /// Seconds between unsolicited advertisements (`PROP_ADVERT_INTERVAL`)
117    /// — UINT32, 0 to send none. An advertisement carries the signed node
118    /// identity and goes out with no flood hops and no source route, so it
119    /// reaches the neighbours that can hear the device directly and stops
120    /// there. The accepted range is [`MIN_AUTO_ANNOUNCE_INTERVAL_S`] to
121    /// [`MAX_AUTO_ANNOUNCE_INTERVAL_S`], and the value is a floor rather
122    /// than a period: the device scatters each send later by up to a

124    pub const ADVERT_INTERVAL: u32 = 80;
125    /// Seconds between unsolicited beacons (`PROP_BEACON_INTERVAL`) —

130    /// [`ADVERT_INTERVAL`]. Requires `CAP_ADVERT`.

216/// `PROP_SAVED` values.
217///
218/// A snapshot that exists but cannot be read is distinguishable from no
219/// snapshot at all, and running on an older generation than the one last
220/// written is distinguishable from running on the newest.
221pub mod saved {
222    /// Nothing is saved.
223    pub const NONE: u8 = 0;
224    /// The newest saved generation is in effect.
225    pub const CURRENT: u8 = 1;
226    /// A newer generation was rejected; an older one is in effect.
227    pub const FALLBACK: u8 = 2;
228    /// A snapshot exists but no generation could be read.
229    pub const UNREADABLE: u8 = 3;
230}

299/// Shortest accepted `PROP_ADVERT_INTERVAL` / `PROP_BEACON_INTERVAL`, in
300/// seconds.
301///
302/// An absolute floor, and one a device may only ever round *up* from:
303/// scheduling jitter delays an announcement and never brings it forward,
304/// so no configuration can put an unsolicited broadcast on the air more
305/// often than this. The duty ledger remains the airtime control; this is
306/// what keeps a mistyped interval from spending the whole budget on
307/// announcements before anything else can speak.
308pub const MIN_AUTO_ANNOUNCE_INTERVAL_S: u32 = 20 * 60;
309
310/// Longest accepted `PROP_ADVERT_INTERVAL` / `PROP_BEACON_INTERVAL`, in
311/// seconds.
312///
313/// A ceiling on how stale the mesh's picture of a node may get while that
314/// node still considers itself to be announcing. Past a day the schedule
315/// has stopped being one, and 0 says so more honestly.
316pub const MAX_AUTO_ANNOUNCE_INTERVAL_S: u32 = 24 * 60 * 60;
317
318/// Default `PROP_ADVERT_INTERVAL`, in seconds.
319pub const DEFAULT_ADVERT_INTERVAL_S: u32 = 4 * 60 * 60;

321/// Default `PROP_BEACON_INTERVAL`, in seconds.
322pub const DEFAULT_BEACON_INTERVAL_S: u32 = 60 * 60;
