3//! The standalone messenger interface for communicator-class UMSH devices.
4//!
5//! A communicator provides the whole UMSH experience on the device: it has
6//! a color screen, a text keyboard, and navigation controls, and a phone is
7//! optional. The T-LoRa Pager is the first target; its mockup in
8//! `docs/ux/src/hardware/mockups/` is the reference design.
9//!
10//! - [`model`]: what the screens show, filled in by the device.
11//! - [`ui`]: the screens themselves, as Buoyant views.
12//! - [`input`]: the inputs a board reports, and what they mean.
13//! - [`avatar`]: peer and channel avatars, following the iOS rules.
14//! - [`font`], [`icon`], [`theme`]: typefaces, icons, colors, and sizes.
15//! - [`fixture`]: stand-in content (the `fixture` feature).
16//!
17//! [`buoyant`] is re-exported so a device drives the interface with the
18//! same version it was built against.
19
