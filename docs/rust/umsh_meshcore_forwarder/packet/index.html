The MeshCore v1 frame: parsing, the duplicate identity, and building the frames a forwarder emits.

A frame is a header octet, two transport codes when the route type carries them, a path-length octet, the path, and the payload:

header | [code0 code1] | path_len | path[count × size] | payload

The header packs the route type (bits 0–1), the payload type (bits 2–5), and the version (bits 6–7). The path-length octet packs the per-entry hash size less one (bits 6–7; 3 is reserved) and the entry count (bits 0–5).

Parsing follows the baseline dispatcher’s acceptance rules exactly, except that every read is bounds-checked: a frame too short for the fields its header promises is rejected rather than read past its end.
