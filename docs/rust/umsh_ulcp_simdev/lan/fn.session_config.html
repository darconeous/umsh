pub fn session_config(dev_version: &'static str) -> SessionConfig
Expand description

The shape of a virtual radio, reporting itself as dev_version.

Spare, like a bridge’s host interface: no hardware to describe and no node behind it. The PHY settings it reports are the default profile’s, fixed; the frames it sends are transmitted later by whichever LoRa radios forward them, so the frame time a host’s MAC derives from these is an estimate either way. The duty limit is left open—sending to the group spends no airtime—and the radios’ ingress limits are the control that means something.

The configuration borrows a duty ledger for the life of the process, so a caller builds one per device it runs, not one per attach.
