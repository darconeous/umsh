Expand description

CliSession sized for typical desktop and tracker-class targets.

Uses NoPeerStore, NoChannelStore, and NoPowerControl — state is tracked in-memory only and /poweroff is a no-op. For embedded targets with flash storage and a real shutdown path, use CliSession<…> directly.

Capacity defaults: 16 peers, 16 aliases, 8 channels, 64 events, 256-byte command line. Replace with an explicit CliSession<…> when these defaults are wrong for the target.
