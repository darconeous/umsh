Struct DutyLedger 

Source 
pub struct DutyLedger { /* private fields */ }
Expand description

The shared duty ledger: one DutyTracker plus the active limit and modulation parameters, behind a blocking mutex so it can sit in a static and be consulted from every radio client’s TX path.

All time comes in as caller-supplied now_ms (the same monotonic clock the session uses), keeping the ledger free of any platform timer dependency.

pub fn admit(&self, now_ms: u64, frame_len: usize) -> Result<u32, DutyExceeded>

Admission check for a client that knows only its frame length (the device node’s radio path): compute the airtime at the active modulation and test it against the combined budget. Returns the airtime to Self::record once the transmit completes. Does not itself record — refused frames and failed transmits must not consume budget.
