Module lan

Expand description

The LAN virtual radio: a soft ULCP device in this process whose PHY is the LAN bearer’s multicast group.

The device is the production session on a file-backed platform, so it has an identity and saved configuration of its own that persist from one invocation to the next. The tool reaches it over an in-memory byte pipe carrying the same HDLC-Lite framing a wire does, and everything above that—attach, the mesh session, every command—is unchanged.

What the device transmits is sent to the group, where every radio with its bearer enabled hears it; what any participant sends to the group is received unmeasured, since nothing here measured it.
