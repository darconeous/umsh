Read or manage the device’s Bluetooth bonds.

Over Bluetooth, clearing severs this very link — the bond that carried the command is one of the bonds deleted — so the handle is detached afterward for the same reason reboot detaches. Over a cable or the mesh nothing is disturbed, but detaching costs only a reattach and keeps one rule instead of two.
