Module info 

Source
Expand description

info: what the device says about itself, in as few exchanges as it can be asked in.

The report is a list of topics (topics::TOPICS), each a set of properties and two renderings of them. Everything a run needs is fetched in one CMD_PROP_MULTI_GET — plus the two that cannot share one — so a whole report costs about what a single property used to.

Naming a topic asks for that topic alone, which over the mesh is the difference between a question and an errand.
