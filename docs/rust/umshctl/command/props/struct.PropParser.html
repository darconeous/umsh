Struct PropParser 

Source 
pub struct PropParser;
Expand description

Parses a PropArg and offers the property names as its possible values, which is what the REPL’s completer reads.

The names are a menu, not the whole grammar—numbers and the spec’s spellings still parse. Each argument that takes one sets hide_possible_values, or --help would list every property there.
