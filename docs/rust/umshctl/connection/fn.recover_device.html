Expand description

Bring a handle’s link back, attempt after attempt, until it is back or abort resolves.

Quiet when the first attempt succeeds: from the user’s side the connection never went anywhere, and a reattach that takes a moment is not worth a line. From the first failed attempt on, every retry is narrated on stderr, so a command that has gone quiet is explained and the next wait is known. Never stdout, which may be carrying JSON.
