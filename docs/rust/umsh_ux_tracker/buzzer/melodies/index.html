Pre-baked melodies for the standard firmware events.

Statics§

BEACON_ACK
Short confirmation blip after a beacon is transmitted.
DO_SILENCE
Short low blip played just before the buzzer goes silent.
LOCATE
Locate alert: a two-tone warble, deliberately unlike any notification the device makes in normal operation, so it reads as “come find me” rather than “you have mail”. Played on repeat by BuzzerEngine::play_alert, which supplies the gap between passes.
POWER_OFF
Falling chirp: 2000 → 1500 → 1000 Hz.
POWER_ON
Rising chirp: 1000 → 1500 → 2000 Hz.
UNSILENCE
Bright blip played when the buzzer is un-silenced.
